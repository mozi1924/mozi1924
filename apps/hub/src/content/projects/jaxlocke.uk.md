# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1et2n6jX_V7_5opSXKrzOeEGHF_MvvW0T

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](https://github.com/mozi1924/jaxlocke.uk/blob/main/.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
